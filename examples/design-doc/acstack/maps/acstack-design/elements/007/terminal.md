# Terminal output

What the developer sees when checking and serving the design. The text comes from the existing `design-doc` command.

```text
$ acstack design-doc acstack-design --check
Design doc ACStack design review: 9 elements, 0 open human questions, 0 unresolved map items

$ acstack design-doc acstack-design
Review ACStack design review at http://localhost:47811/
Waiting for your review. Ctrl+C stops.
```
